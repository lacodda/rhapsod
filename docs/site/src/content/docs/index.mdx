This is the v0.1 foundation: the server, the app shell and the release rails stand, and the architecture is recorded. The library index, the reading view, progress, notes and repetition are what the next releases build.
</Aside>

## What rhapsod is

<CardGrid stagger>
	<Card title="Files in, reading out" icon="document">
		The library is a directory of markdown with frontmatter, published from wherever you write. The server indexes it and never edits it; what it remembers about your reading lives in one SQLite file.
	</Card>
	<Card title="Reads anywhere" icon="laptop">
		The app caches the whole library and queues what you do offline. It syncs when the Pi is reachable, and no VPN is assumed.
	</Card>
	<Card title="One container on a Pi" icon="rocket">
		A single process serves the API and the app; state is one file in one volume, and a backup is a copy of it.
	</Card>
	<Card title="Remembering, not just reading" icon="star">
		Progress, notes and highlights - and spaced repetition over the lines you marked, so the library stays read rather than merely finished.
	</Card>
</CardGrid>
