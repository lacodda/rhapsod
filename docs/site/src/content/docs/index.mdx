<Aside type="caution" title="Early days">
A directory of markdown is a library you can read, and the reader keeps your place: where you stopped, what you have finished, and what to read next. It holds your notes and highlights, reads offline and syncs when you are home, and brings finished pieces back on a schedule so the library stays read rather than merely finished.
</Aside>

## What rhapsod is

<CardGrid stagger>
	<Card title="Files in, reading out" icon="document">
		The library is a directory of markdown with frontmatter, published from wherever you write. The server indexes it and never edits it; what it remembers about your reading lives in one SQLite file.
	</Card>
	<Card title="Keeps your place" icon="open-book">
		Where you stopped is a paragraph, not a scroll position, so the same number is the same sentence on a phone and on a desktop - and it never moves backwards when a stale device syncs.
	</Card>
	<Card title="One container on a Pi" icon="rocket">
		A single process serves the API and the app; state is one file in one volume, and a backup is a copy of it.
	</Card>
	<Card title="Remembering, not just reading" icon="star">
		Progress, notes and highlights - and spaced repetition over the lines you marked, so the library stays read rather than merely finished.
	</Card>
</CardGrid>
